## 各模块详细选型

### 电机驱动：TB6612FNG

| 参数 | 规格 |
|---|---|
| 型号 | **TB6612FNG** (东芝) |
| 持续电流 | 1.2 A (连续) / 3.2 A (峰值) |
| 电压 | 2.5 V ~ 13.5 V |
| 控制方式 | 双 H 桥 (1 块 = 2 个电机) |
| **用量** | **2 块 = 4 个电机** |
| 价格 | ~¥7 / 块 |

**与 TM4C123 接线：**

| 信号 | TM4C123 引脚 | 说明 |
|---|---|---|
| PWMA | M1_PWM (PB6) | PWM 调速 |
| AIN1 | M1_IN1 (PA2) | 方向 |
| AIN2 | M1_IN2 (PA3) | 方向 |
| PWMB | M2_PWM (PB7) | PWM 调速 |
| BIN1 | M2_IN1 (PA4) | 方向 |
| BIN2 | M2_IN2 (PA5) | 方向 |

> TB6612FNG 逻辑输入兼容 3.3V 和 5V，TM4C123 输出 3.3V 可直接驱动。

**电源接线要点：**
- `VM` 接 12V 电池（或 12V 降压输出）
- `VCC` 接 3.3V（逻辑电源，与 TM4C123 共用 3.3V）
- `GND` 与 MCU 共地，电机电源与逻辑电源必须共地
- `STBY` 接 3.3V（使能待机模式）
- 每块驱动板需独立连接 MCU 对应引脚

### 备选驱动

| 型号 | 价格 | 特点 | 缺点 |
|---|---|---|---|
| **L298N** | ~¥8/块 | 经典，2A 持续 | 压降大 (~2V)，发热严重 |
| **DRV8833** | ~¥6/块 | 小体积，1.5A | 电流偏小，四电机需多块 |
| **A4950** | ~¥10/块 | 2A，单路独立 | 四电机需 4 块 |

**推荐排序：TB6612FNG > DRV8833 > L298N > A4950**

## IMU 姿态传感器

### 推荐：MPU6050

| 参数 | 规格 |
|---|---|
| 型号 | **MPU6050** (InvenSense) |
| 接口 | I2C (地址 0x68) |
| 量程 | 3 轴加速度 + 3 轴陀螺仪 |
| 工作电压 | 3.3 V |
| 价格 | ~¥8 |

**接线：**

| MPU6050 引脚 | TM4C123 |
|---|---|
| SDA | PB3 (I2C0 SDA) |
| SCL | PB2 (I2C0 SCL) |
| VCC | 3.3V |
| GND | GND |
| AD0 | GND (I2C 地址 = 0x68) |

**软件集成要点：**
- 读取 MPU6050 原始数据后需姿态解算（互补滤波 / Mahony/Madgwick）
- TivaWare 无内置 MPU6050 驱动，需自行实现或引用 GitHub 开源库
- 可用于小车姿态估计、转弯补偿、防侧翻检测

## 超声波测距

### 推荐：HC-SR04P

| 参数 | 规格 |
|---|---|
| 型号 | **HC-SR04P** (3.3V 版本) |
| 接口 | GPIO (Trig + Echo) |
| 量程 | 2 cm ~ 4 m |
| 精度 | ~3 mm |
| 价格 | ~¥3 / 个 |

> ⚠ 注意区分：普通 HC-SR04 是 5V 逻辑，`HC-SR04P` 是 3.3V 兼容版。
> 若使用普通 HC-SR04，Echo 引脚输出 5V，需电平转换后再接 3.3V 的 TM4C123。

**接线：**

| HC-SR04P | TM4C123 |
|---|---|
| VCC | 5V (由 USB 或 BEC 供电) |
| GND | GND |
| Trig | PE4 (GPIO 输出) |
| Echo | PE5 (GPIO 输入 / 或 Timer CCP 捕获) |

**测距实现方式对比：**

| 方式 | 精度 | 说明 |
|---|---|---|
| GPIO 中断 + SysTick 计时 | 一般，~10us (~1.7mm) | 实现简单 |
| Timer Input Capture | 较高 (~1us) | 推荐，硬件计时 |

## 循迹传感器

### 推荐：TCRT5000 反射式模块

| 参数 | 规格 |
|---|---|
| 型号 | **TCRT5000 模块** (红外反射) |
| 接口 | GPIO (数字输出) 或 ADC (模拟输出) |
| 检测距离 | 1 mm ~ 15 mm |
| 价格 | ~¥2 ~ 3 / 个 |

**两种接线方式：**

| 输出类型 | TM4C123 连接 | 适用场景 |
|---|---|---|
| 数字 (DO) | GPIO 输入 | 黑白线检测，简单可靠 |
| 模拟 (AO) | ADC 通道 (PE0~PE3) | 灰度检测，更精细 |

**推荐配置：** 4 路循迹，DO 接 4 路 GPIO（PA6, PA7, PC6, PE2），简单高效。

### 备选

| 方案 | 说明 | 价格 |
|---|---|---|
| **5 路循迹板** | 集成 5 个 TCRT5000 + 排针 | ~¥15 |
| **自制模块 (DIY)** | 单独 IR LED + 光敏电阻 | ~¥1/个 |

## OLED 显示屏

### 推荐：SSD1306 (0.96", I2C)

| 参数 | 规格 |
|---|---|
| 型号 | **SSD1306** (128×64 像素) |
| 接口 | I2C (地址 0x3C) |
| 电压 | 3.3V |
| 价格 | ~¥10 |

**接线：**

| OLED 引脚 | TM4C123 |
|---|---|
| SDA | PB3 (I2C0 SDA) — 与 MPU6050 共用 |
| SCL | PB2 (I2C0 SCL) — 与 MPU6050 共用 |
| VCC | 3.3V |
| GND | GND |

> I2C 总线可挂多个设备：MPU6050 (0x68) 和 OLED (0x3C) 地址不同，可共用 SDA/SCL。

**显示内容建议：**
- 电池电压 / 电量
- 电机转速
- IMU 姿态
- 循迹状态
- 调试信息（PWM 占空比、PID 误差）

## 电源方案

### 推荐：3S LiPo (11.1V)

MG513 电机额定 12V，3S LiPo 满电 12.6V，完全匹配。

### 电源拓扑

```
11.1V 电池 (3S)
    ├── 12V → TB6612FNG VM (电机电源)
    ├── 12V → LM2596 降压 → 5V
    │           ├── 传感器 VCC
    │           └── 5V → AMS1117-3.3 → 3.3V
    │                   ├── TM4C123
    │                   ├── HC-05
    │                   ├── MPU6050
    │                   ├── SSD1306
    │                   └── TCRT5000 (VCC)
    └── 12V → 分压电路 → ADC (PE0) 电池电压检测
```

### 电源模块

| 模块 | 型号 | 价格 |
|---|---|---|
| 12V→5V 降压 | **LM2596 模块** (可调，设 5V) | ~¥8 |
| 5V→3.3V 稳压 | **AMS1117-3.3** (线性稳压) | ~¥2 |
| 电池检测 | 2 × 10kΩ 分压电阻 | ~¥0.1 |
| 连接器 | XT60 或 JST 接口 | ~¥3 |

## 电平转换

### 推荐：TXS0108E

| 参数 | 规格 |
|---|---|
| 型号 | **TXS0108E** (8 通道双向) |
| 电压 | 3.3V ↔ 5V |
| 速率 | ~100 kHz (I2C 和 GPIO 足够) |
| 价格 | ~¥5 |

**使用场景：**
- 若驱动板 (TB6612FNG) 要求 5V 逻辑输入
- 若 HC-SR04 (5V) 的 Echo 需电平转换
- TCRT5000 模块若输出 5V 逻辑

若全部选用 3.3V 兼容模块（HC-SR04P、3.3V TCRT5000），可省略电平转换。

## 采购注意事项

1. **MG513 电机编码器**：购买时确认是否带编码器，分辨率常见 390 PPR 或 520 PPR，影响测速精度。

2. **TB6612FNG 模块**：选择带散热片和大电容的版本，避免 QFN 封装焊接困难。

3. **HC-05 与 HC-SR04P 区分**：
   - HC-**05** 是蓝牙，`05` 是型号
   - HC-**SR04P** 是超声波，`SR` 代表 Sonic Range
   - 两者外观相似，采购时注意标题

4. **电池安全**：3S LiPo 建议配 XT60 或 JST 连接器，并准备平衡充。

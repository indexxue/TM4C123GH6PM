# 四轴 MG513 小车 + 多传感器方案 MCU 选型参考

针对 4 轴 MG513 电机 + 多传感器小车的 MCU 选型分析

---

## 一、项目需求与 MCU 资源对照

| 资源 | 最小需求 | 推荐配置 |
|---|---|---|
| PWM 通道 | 4 路 (4 电机) | 8 通道以上 (备用) |
| 编码器输入 | 8 路 (4 电机 × AB) | 8 路 GPIO 或硬件 QEI |
| UART | 1 路 (蓝牙) | 2-3 路 (调试 + 蓝牙 + GPS) |
| I2C | 1 路 (IMU) | 2 路 (IMU + OLED 显示) |
| ADC | 2 路 (电池 + 传感器) | 4-6 路 (扩展) |
| 主频 | ≥ 48 MHz | ≥ 80 MHz |
| Flash | ≥ 64 KB | ≥ 128 KB |
| SRAM | ≥ 8 KB | ≥ 32 KB |
| 封装 | 小型化优先 | LQFP-48 或 LQFP-64 |

---

## 二、候选芯片对比

### 2.1 参数对比

| 芯片 | 内核 | 主频 | Flash | SRAM | 价格 (参考) | 适用场景 |
|---|---|---|---|---|---|---|
| **TM4C123GH6PM** | Cortex-M4F | 80 MHz | 256 KB | 32 KB | ~¥25 | **推荐首选** |
| **STM32F103C8T6** | Cortex-M3 | 72 MHz | 64 KB | 20 KB | ~¥8 | 预算有限 |
| **STM32F411CEU6** | Cortex-M4F | 100 MHz | 512 KB | 128 KB | ~¥25 | 性能过剩 |
| **STM32F405RGT6** | Cortex-M4F | 168 MHz | 1 MB | 192 KB | ~¥35 | 高性能扩展 |
| **ESP32-WROOM** | Xtensa LX6 | 240 MHz | 4 MB | 520 KB | ~¥15 | 带 WiFi |
| **RP2040** | Cortex-M0+ | 133 MHz | 2 MB (外置) | 264 KB | ~¥5 | 极简 |
| **GD32F303** | Cortex-M4F | 120 MHz | 256 KB | 48 KB | ~¥12 | 国产替代 |

### 2.2 详细分析

#### TM4C123GH6PM（推荐）

| 维度 | 评价 |
|---|---|
| **生态** | TivaWare DriverLib 成熟，SysConfig 图形化配置，TI 官方支持 |
| **定时器** | 6 组 Timer (12 路 PWM)，满足 4 电机需求 |
| **通信** | 8 路 UART、6 路 I2C、4 路 SPI，资源充裕 |
| **性能** | 硬件 FPU，适合 PID 运算 |
| **编码器** | QEI 模块 + 64-pin 封装，引脚够用 |
| **价格** | 中等 (~¥25)，性价比合理 |
| **缺点** | 国内生态不如 STM32 丰富 |
| **功耗** | 中等 (~50mA @ 80MHz) |

**结论：** 四轴 MG513 小车 + 多传感器方案的最佳平衡选择。

#### STM32F103C8T6 (Blue Pill)

| 维度 | 评价 |
|---|---|
| **价格** | 极低 (~¥8)，入门首选 |
| **生态** | 资料最多，社区最大 |
| **定时器** | 4 组 Timer (部分支持 PWM)，勉强够用 |
| **编码器** | 硬件编码器接口 (TIMx_ETR)，但仅 2 组 |
| **性能** | 无 FPU (Cortex-M3)，PID 运算较慢 |
| **存储** | 64KB Flash，复杂程序可能不够 |
| **主频** | 72 MHz，略低于需求 |
| **封装** | 常见 LQFP-48，引脚紧张 (4 电机已极限) |

#### STM32F411CEU6 (Black Pill)

| 维度 | 评价 |
|---|---|
| **性能** | 100 MHz、512KB Flash、128KB SRAM，过剩 |
| **内核** | 硬件 FPU (Cortex-M4F) |
| **定时器** | 9 组 Timer，资源充足 |
| **扩展** | USB OTG、DCMI 等高级外设 |
| **封装** | QFN-48，焊接难度较高 |
| **价格** | ~¥25，与 TM4C123 相当 |
| **缺点** | 引脚较少，48-pin 仅约 30 个 GPIO |

#### ESP32

| 维度 | 评价 |
|---|---|
| **优势** | WiFi + 蓝牙内置，无需外接模块 |
| **性能** | 双核 240 MHz，算力过剩 |
| **价格** | ~¥15，含无线功能 |
| **缺点** | 实时性不如专用 MCU，FreeRTOS + WiFi 栈占用资源 |
| **PWM** | LEDC 模块与通用 Timer 行为不同 |
| **ADC** | 非线性、精度一般，不适合精密传感 |
| **编码器** | 无硬件 QEI，需 RMT 或 GPIO 中断模拟 |

**结论：** 适合 WiFi/蓝牙遥控 + 简单小车，不适合精密 PID 控制。

#### RP2040 (Raspberry Pi Pico)

| 维度 | 评价 |
|---|---|
| **价格** | 极低 (~¥5)，最便宜 |
| **特色** | PIO 状态机可灵活实现外设 |
| **生态** | 支持 MicroPython，上手快 |
| **性能** | Cortex-M0+ 无 FPU，算力不足 |
| **ADC** | 仅 4 通道，不够用 |
| **定位** | 教育/原型，不适合正式产品级 MCU |

## 三、TM4C123GH6PM 资源匹配度

### 资源占用估算

```
4 轴 MG513 电机
├── 4 路 PWM (Timer0A/B + Timer1A/B)         ← 2 组 Timer = 4 路
├── 8 路方向 GPIO                             ← 方向控制
└── 4 组编码器 (8 根信号线)
    ├── QEI 硬件                             ← 2 组
    └── GPIO 中断捕获                         ← 2 组

传感器
├── 蓝牙 UART0                               ←
├── IMU I2C0                                 ←
├── OLED I2C0 (共用)                         ←
├── 循迹传感器 ×4                            ← 4 路 GPIO
├── 超声波模块 ×2                            ← 4 路 GPIO
└── 电池电压 ADC                             ← 1 路 ADC 通道
└── 蜂鸣器 PWM/GPIO                          ←

调试
├── SWD 接口                                 ←
└── UART 调试                                ←

剩余 GPIO 余量: ~30 / 43 个                   ← 充裕
```

### 综合评分

| 维度 | 评分 | 说明 |
|---|---|---|
| 性能 | ★★★★☆ | 80 MHz + FPU，PID 无压力 |
| 外设 | ★★★★★ | Timer/UART/I2C/ADC 全覆盖 |
| 开发体验 | ★★★★☆ | SysConfig + TivaWare + 本地文档 |
| 成本 | ★★★★☆ | ~¥25，合理区间 |
| 扩展性 | ★★★★☆ | 引脚余量充足 |
| 封装 | ★★★★☆ | 64-pin 封装，46 个 GPIO，够用 |

**总评：** TM4C123GH6PM 是 4 轴 MG513 多传感器小车的最佳性价比选择。

## 四、选型建议

### 选择 TM4C123GH6PM 的理由

- 已有 LaunchPad 开发板和配套 PCB
- 熟悉 TI 工具链 (SysConfig + TivaWare) 生态
- 不需要 WiFi (可通过 UART 接蓝牙模块)
- 需要硬件 FPU 做 PID 运算
- 4 轴 MG513 电机 + 传感器，引脚需求约 6 组外设

### 其他场景推荐

| 场景 | 推荐芯片 | 理由 |
|---|---|---|
| 需要 WiFi 遥控 + 低成本 | ESP32 | 内置 WiFi，~¥15 |
| 高性能扩展 (6+ 电机) | STM32F405RGT6 | 100-pin LQFP，更多 GPIO |
| 需要摄像头视觉 | STM32F405 + OV2640 | DCMI 接口 |
| 国产替代 / 降本 | GD32F303 (兆易) | ~¥12，STM32 兼容 |
| 需要 Linux 级功能 | ESP32 + 上位机 | 分工明确，各取所长 |

### 升级路径

```
当前       → 中期         → 远期
TM4C123     STM32F4       STM32H7 / i.MX RT
80 MHz      168 MHz       400+ MHz
¥25          ¥35           ¥60+
```

当前 TM4C123GH6PM 完全满足项目需求，无需过早升级。

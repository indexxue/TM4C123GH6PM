# RC Controller 使用说明

**产品**：`projects/rc-controller`  
**固件版本**：见 UART7 启动日志或菜单 **About**  
**设计文档**：[rc-joystick-menu-design.md](./rc-joystick-menu-design.md)

面向手持遥控器的日常操作说明；开发/编译见 [projects/rc-controller/README.md](../projects/rc-controller/README.md) 与 [build.md](./build.md)。

---

## 1. 产品概览

TM4C123 双摇杆遥控器，经 **蓝牙 UART0** 向四轴小车发送 `DRIVE` 遥控帧（协议见 [bluetooth-protocol.md](./bluetooth-protocol.md)）。

| 硬件 | 说明 |
|------|------|
| 左摇杆 JS1 | **Y 轴 = 油门**，**X 轴 = 转向**（仅在 **DRIVE** 会话中发控） |
| 右摇杆 JS2 | 显示与校准；**本阶段不参与 DRIVE** |
| JS1 按键 | 主屏 **短按切换** IDLE↔DRIVE；菜单内 **确认 (ENTER)**；校准向导 **下一步/保存** |
| JS2 按键 | 主屏 **长按 ≥1.5 s 进菜单**（DRIVE 中会先停控）；菜单内 **返回 (BACK)**；校准时 **取消** |
| 1.14" 屏 | 240×135 横屏：主屏双十字 + 设置菜单 + 校准向导 |
| 蓝牙 | HC-05 等模块接 UART0，115200 8N1 |

---

## 2. 首次上电

1. 给遥控器与小车分别上电；小车量产固件需已开启蓝牙协议层。
2. 主屏约 1 s 内出现 **深蓝底 + 双十字准星**；顶栏 **BAT**、会话状态 **IDLE**、**LINK OK** 或 **LINK --**。
3. **LINK OK** 表示已与小车完成 `HELLO` 握手；若为 **LINK --**，检查蓝牙配对/连线与小车上电状态。
4. 底栏提示 **JS1:arm hold JS2:menu**（短按左键进遥控；长按右键进设置）。

**建议**：首次使用前完成一次 **摇杆校准**（见 §5），保证十字方向与物理推杆一致、两端能稳定到 ±1000。

---

## 3. 主屏（HOME / IDLE）

```
┌──────────────────────────────────────┐
│ RC  BAT xx%   IDLE      LINK ●/○     │
│         JS1                JS2       │
│   ┌────┐              ┌────┐       │
│   │  + │              │  + │       │  ← 十字中心=死区；点=当前 cmd
│   └────┘              └────┘       │
│ JS1:arm hold JS2:menu                │
└──────────────────────────────────────┘
```

| 元素 | 含义 |
|------|------|
| IDLE / DRIVE | 会话状态：空闲不发控 / 遥控中 |
| 十字准星 | 左 JS1、右 JS2 各一组；**点位置**对应当前归一化指令（-1000…+1000） |
| 点变红 | 对应摇杆 **按键按下** |
| BAT | 电池电量百分比（≤20% 黄色告警） |
| LINK | 蓝牙链路是否就绪 |

**轴向约定**（与物理推杆一致时为准）：

- X：左 → 负，右 → 正  
- Y：下 → 负，上 → 正  

若方向相反，可在菜单 **Axis Invert** 中逐轴反转，或重新校准。

## 4. 日常遥控

1. 确保 **LINK OK**，双杆松手回中（死区内）。
2. **短按 JS1 键** 进入 **DRIVE 遥测页**（全屏车况，无双十字）。若未回中或无链路，底栏短暂提示 `CENTER` / `NO LINK`。
3. **左摇杆 JS1** 控车；页上显示电量 / 超声 / 姿态 / 速度 L/R / 编码器；缺数据为 **`null`**。
4. **JS2 短按松手** → 订阅页（勾选电量/超声/电机 RPM → **Save** 写 NVS 并 `SUBSCRIBE`，或 **Cancel**）；返回后仍保持遥控会话。
5. 松手回中后再 **短按 JS1** 退出 → `DRIVE_STOP` + 退订可选通道，回 **IDLE**（推杆中按键不会退出，防误触）。
6. **链路闪断** 仍留在 DRIVE：顶栏变 `LINK --`、停驶；恢复后自动重订并续控（不踢回 IDLE）。主动退出仍须回中后短按 JS1。
7. **JS2 长按 ≥1.5 s** 停控并进 Settings。

> **安全**：仅 DRIVE 遥测页发运动指令；订阅页 / 菜单 / 校准均 mute。

---

## 5. 进入设置菜单

| 操作 | 效果 |
|------|------|
| 主屏 **长按 JS2 键 ≥1.5 s** | 进入 **Settings**（若在 DRIVE 中会先停控）；菜单退出后回到 **IDLE** |
| 菜单内 **JS2 短按** | 返回上一级；在根菜单则 **退出回 HOME** |
| 菜单内 **JS1 上下/左右** | 移动光标 / 调节参数（PARAM 项） |
| 菜单内 **JS1 短按** | 确认当前项 |

导航采用 **边沿触发**：推杆越过阈值产生一次事件，**回中后才能再次触发**，避免连跳。

### 菜单结构

| 菜单项 | 功能 |
|--------|------|
| **Calibrate...** | 进入双杆校准向导 |
| **Monitor** | 四轴 **raw/cmd** 实时监视（格式 `ADC值/映射值`） |
| **Deadband** | 死区（ADC 计数，默认 120；左右调节步进 10） |
| **Axis Invert** | J1X / J1Y / J2X / J2Y 反转开关 |
| **Reset Cal** | 恢复默认校准（需二次确认 **YES reset**） |
| **About** | 产品名 / 固件版本 / 序列号 |

**Deadband**、**Axis Invert** 修改后 **立即生效并写入 NVS**，无需单独保存。

## 6. 摇杆校准向导

路径：**Settings → Calibrate...**

双杆 **一起** 校准，分三步：

### 步骤 1/3 — 回中（Center both sticks）

1. **双杆松手置于中心**，保持稳定。
2. 按 **JS1 键** 采样四轴 **center** 值。

### 步骤 2/3 — 极限（Push all extremes）

1. 将 **两杆分别推满** 左、右、上、下（十字形行程，**不要画圈**）。
2. 固件实时跟踪各轴 **min/max**。
3. 屏上显示 **reach n/4**：每轴相对回中点，**两侧行程均需 ≥600 ADC** 才算达标。
4. 当 **ok 4/4** 后，按 **JS1 键** 进入确认。

### 步骤 3/3 — 确认（Save calibration?）

1. 检查十字上点位置是否合理。
2. **JS1 键** → 写入 NVS 并返回菜单。  
3. **JS2 键** → **取消**，不覆盖已有校准。

**取消**：任一步骤按 **JS2 键** 放弃，不写入 NVS。

### 校准验收

| 检查项 | 期望 |
|--------|------|
| 主屏十字方向 | 与物理推杆一致 |
| 推满两端 | 映射 cmd 接近 **±1000** |
| 回中 | cmd 在死区内 ≈ **0** |
| 重启后 | 校准仍有效（NVS `cal/joy`） |

## 7. 通道监视（Monitor）

用于排查 ADC 与映射是否正常：

| 行 | 含义 |
|----|------|
| J1X / J1Y | 左摇杆 X/Y：`原始ADC/映射cmd` |
| J2X / J2Y | 右摇杆 X/Y：同上 |

推杆时观察 raw 是否随物理方向变化；cmd 是否在 ±1000 范围内。

---

## 8. 与小车连接

1. 遥控器 **UART0** 接蓝牙模块；小车端同样使用协议栈（非厂测 `cmd` 口）。
2. 上电后遥控器发 `HELLO`；主屏 **LINK OK** 即链路就绪。
3. 仅在 **HOME** 模式下发送有效 `DRIVE`；菜单/校准时发 **零指令**。

调试日志走 **UART7**（PE1 TX @ 115200），与蓝牙业务口分离。

## 9. 常见问题

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 十字方向与推杆相反 | 未校准或轴向反了 | 菜单 **Axis Invert** 或重新 **Calibrate** |
| 回中仍有漂移 | 死区过小 / center 偏 | 增大 **Deadband** 或重做步骤 1 回中 |
| 推满到不了 ±1000 | 极限未推够 | 校准步骤 2 确保 **4/4** 后再确认 |
| LINK 一直 -- | 蓝牙未连 / 小车未起协议 | 查配对、小车固件、UART0 接线 |
| 菜单里小车仍动 | 异常 | 正常应禁发；查是否误在 HOME、或小车端非零指令残留 |
| 屏色偏 / 上下颠倒 | 屏批次差异 | 改 `source/rc_lcd_cfg.h` 中 `RC_LCD_FLIP_UD`、`RC_LCD_BGR` 后重编 |

## 10. 显示与主题（开发者）

编译期宏位于 `projects/rc-controller/source/rc_lcd_cfg.h`：

| 宏 | 默认 | 说明 |
|----|------|------|
| `RC_LCD_FLIP_UD` | 1 | 横屏上下翻转 |
| `RC_LCD_BGR` | 0 | RGB 色序（本板 BGR=1 时背景会偏色） |
| `RC_LCD_COLOR_*` | 深蓝主题 | 背景/前景/准星/摇杆点颜色 |

修改后执行 `.\build.cmd rc-controller` 重新烧录。
